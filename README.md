# Simple SpeedDial — Widget Examples

Ready-to-use custom widget templates and guides for **Simple SpeedDial**.

## Widget Types

- **[Custom Search Widgets](./search/README.md)** (`search/`) — Search bars (simple URL templates, multi-variable JSON templates, grouped engines, and prefix auto-routing).
- **[TimeZone Widgets](./timezone/README.md)** (`timezone/`) — Multi-timezone live clocks with an interactive TimeZone Calculator.
- **[REST / JSON Status Widgets](./rest-status/README.md)** (`rest-status/`) — Live service & homelab health badges with JSONPath extraction, rule matching, extra metrics, and optional Vault-encrypted auth.
- **[Notes / Scratchpad Widgets](./notes/README.md)** (`notes/`) — Persistent notes, checklists, and timed reminders.
- **[RSS / Atom Feed Widgets](./rss/README.md)** (`rss/`) — Live RSS/Atom feed readers with unread counts, grouping, and a built-in reader modal.

## How to Use

1. Open **Settings → Custom Widgets** in Simple SpeedDial.
2. Click **📤 Import** and select any `.json` file from the folders above — or paste its raw `https://...` URL and click **🌐 Load from URL**.
3. Place and order the imported widget in **Settings → Appearance → Widgets**, then click **Save**.
